## 2026-10-29 — Bounded HTTP body stream progress and fail-closed cancellation (PR #88)

The shared JSON reader for Google sign-in (8 KiB) and worker publication (256 B), plus the previously added byte-empty-body reader for worker opt-in/logout/unpublish, accepted unbounded sequences of **zero-length stream chunks** because the byte counter never advanced.
