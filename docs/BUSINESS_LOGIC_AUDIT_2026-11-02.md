# JODLO — nonvisual business action / outcome audit (2026-11-02)

**Baseline:** `main` `989b3974f821ed72230eafd34d0539efdf5bc5b9` (2026-11-02); foundation and native build checks on this exact SHA passed before this audit. This document records inspected source and existing local test evidence, **not** live/cloud/device acceptance or numerical code coverage. **Scope:** API, D1, approved policy and simulated adapters only; Android implementation is intentionally not the next engineering priority.

**Product contract:** New JODLO (not Finworkar migration); one customer account may explicitly opt into worker; only Hindi (Devanagari) and English; all legitimate trades in full **889 historical Category / 7,267 Service** review scope, not a ten-category cap. Historic source does **not** equal active catalog. Bilaspur and Raipur are approved city *names*, not real locality handling. First contact is **Agora in-app Internet AUDIO** initiated by customer (no telephone/PSTN, no mandatory request-first); worker's independent receive-calls preference is **default OFF**. See [ADR-0006](decisions/0006-shared-account-opt-in-worker.md), [ADR-0008](decisions/0008-hindi-english-only.md), [ADR-0009](decisions/0009-instant-service-publication.md), [ADR-0011](decisions/0011-all-category-coverage-smart-discovery.md), [ADR-0013](decisions/0013-agora-ip-voice-calling.md), [ADR-0014](decisions/0014-explicit-worker-agora-call-opt-in.md).

## Status definitions

- **LOCAL_ROUTE + TESTS:** callable `/api/v1` handler with D1 or test adapters and regression tests; still unconfigured for public traffic.
- **INTERNAL / SIMULATED:** code or pure transition decision with synthetic tests, **not** an authorized external action.
- **MISSING / GATED:** required provider, policy, data, route or operation absent. Never infer behavior from a function name, passing test, mock or stale README.

## Audit outcome and next non-Android engineering sequence

1. **Preserve the real boundary now:** test the approved guest-to-worker publish/unpublish journey and assert that *unapproved* call, report/block, payment, deletion and call-preference HTTP actions remain closed. Add `apps/api/tests/business-logic-action-boundaries.test.mjs` on this branch. This protects against accidental route activation without policy or provider.
2. **Complete the no-policy-needed contract review:** for each module, document actor, authorization origin, input schema, state before/after, idempotency, persistence, race/failure, privacy projection, tests and owner gate. Avoid duplicating the already broad SQLite/Node/Kotlin suites. Prefer a test on demonstrated missing behavior, not repeated mock code.
3. **Prepare the service/Category activation *evidence* (not activation):** continue all 45 source-locked review packets and 2,667 human task ledger. Require qualified Hindi/English, occupational and safety approvals before converting history into active D1 data. No ten-trade truncation.
4. **Before implementing real call admission:** M-005 [14-item operational decision pack](M005_AGORA_OPERATIONAL_DECISIONS.md) remains **PENDING** (online presence, concurrency, blocks, reports, quota, TTL, delivery, privacy, UI and ship gates), plus M-003 data consent/retention and M-006 provider integration. The previously approved Agora AUDIO + independent default-OFF worker consent must not be re-asked.
5. **Then** add server-owned durable coordination and local-only mock integration tests for approved calling and moderation, followed by consent-safe notifications, eventual payments/operations. Do **not** invent policy thresholds, actual worker qualifications, location or real user data to complete a numerical percentage.
6. **Android is not the active priority.** Keep current source unmodified in this phase. Preserve no-staging and no-remote-deployment policy; production is separate M-007 after release readiness.
