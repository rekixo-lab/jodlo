## New application structure (not Firebase transplant)

1. **Native Android / Compose**: Customer Home → browse/search/filters → Category → useful public worker Listing → consent-safe voice; Worker Mode → guided service form → review → publish/edit/unpublish; Account → session, privacy, exports, safety; Notifications/call history only when backend events exist. One shared Google account and optional Worker mode.
2. **Cloudflare Worker API**: modular identity/accounts, signed sessions, reviewed Catalog, Worker service/profile, public discovery, owner publication, block/report/moderation, Agora admission/signaling, FCM delivery, approved payment handlers, privacy export/erasure and staff tools. Every mutation owner-scoped and idempotent; every public projection narrow and fresh.
3. **D1 / R2 / Queues / Durable Objects**: D1 owns accounts/catalog/services/consents/moderation/financial ledgers where approved; R2 owns consent-safe media when built; Queues handle notifications safely; use durable coordination only for a demonstrated race/locking problem. Retention windows and backup/restore must be explicit.
4. **Web**: new JODLO website and legal/help surfaces at `jodlo.rekixo.com`, **separate** API at `api.jodlo.rekixo.com`; never route other REKIXO or Finworkar sites through JODLO.
